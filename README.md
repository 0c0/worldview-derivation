# 世界推导框架（worldview-derivation）

给一句剧情走向，推导出一套**够用的**世界观设定。

它不续写故事，也不批量生成设定。它像做工程一样，把你故事里的世界推到自洽为止：**推得出依据的位置必须落到能拍、能听的具象；推不出依据的位置自动淘汰。**

---

## 它解决什么问题

写设定最常见的两种翻车：

- **太空**——只写下一句"这是座古老的小镇"，真到写戏时什么都撑不住。
- **太满**——为了一个三分钟的场景，把镇上所有人的祖宗十八代、三百年前的战争史全写了，最后一条也没用上。

这个框架的立场是：**叙事的深度，先于世界的广度。**

一个片段级的故事，就只补片段级的世界。要扩，由作者显式指定扩哪一块，其余原样不动。

所以在这里，「不入档」是一个**合法答案**，不是欠账。

## 怎么用

给它一段剧情走向。它按轮推导，每轮固定在**一个由你掌握的闸门**上收口——继续扩深，还是到此为止。

```
你：小红帽进林 → 遇到狼 → 跳河脱生

第 1 轮   定四决 → 拆切片 → 逐片铺八类 → 五审 → 输出更完整的走向 → 你决定是否进入下一轮
第 2 轮   以上一轮的输出为新输入，接着推 ……

交付      八类志书 ＋ 待补清单 ＋ 悬置疑点 ＋ 好点子库
```

**它不会一路推到底。** 每轮结束都把决定权交还给你：继续扩深、换个方向扩宽，还是就这样收了。

## 产出什么

| 产出 | 是什么 |
| --- | --- |
| **八类志书** | 角色 / 事件 / 道具 / 势力 / 场景 / 世相 / 能力 / 法则。每条沿 `本质 → 生成 → 关系 → 终局` 逐格落档，每格必须显式标态：✔填平 / 待补 / 悬置，不许静默跳格 |
| **待补清单** | 范围内的空位，逐条可追溯到推导依据 |
| **悬置疑点** | 剧情需要它存在、但推导不出由来的，占位悬置，永不再问 |
| **好点子库** | 范围之外但确实好的想法，剧情需要时经"扩界通道"回来 |

## 三条硬约束

**一、存在皆由依据推导。**
公理 / 四决 / 法则 / 连带——每一个设定都挂在某个依据上，且必须能回溯到作者真正给过的事实。挂不上的位置淘汰，不硬凑；要凑，先回去问作者。

**二、深度定档，只砍纵向。**
定档之后砍的是"前史、来历、世代"这类**纵向追问**，**不砍横向在场**。"他凭什么敢进林子、穿什么、带什么、听得到什么"——这种当场就要用的因果链，再小的档也得供足。档低 ≠ 这一类存在就不开。

**三、产出即设防。**
每一片推导闭合前必须硬闯五关：

1. **锚点一致**——你写的，和你推导时靠的是不是同一套？
2. **亮相时机**——救场的关键是不是该早现却拖到了收尾？
3. **因果真闭合**——"靠这个能成"，是真成了还是靠运气？
4. **情绪有回声**——惹起的情绪有没有落到实处的回响？
5. **色调没跑偏**——定的基调，和实际写的浓淡一致吗？

判定只有三档：✔过 ｜ ✎须修 ｜ ⊘修不了 → 降格丢进悬置疑点。全过才交付，不许糊过去。

## 一个特色能力：影音在场

把"古色古香""连滚带爬""安静得可怕"这类**状态词**，拆成画面拍得到、声音听得见的具象条目：

> **连滚带爬** → 手撑青石 / 膝盖顶门槛 / 鞋在石板上打滑 / 喘息 / 脚步乱

**声音的缺席同样是声音设计。**"连虫鸣都没有"不是没声音——是"声音的空缺"本身作为情绪压强落进档。

这一层是静态罗列，不编剧情；叙事推进另归情节节点。两者分工分明，互不越界。

## 三层记录

推导结果分三层写，互不污染：

- **真相层**——世界本来的样子，客观叙述，不带解释
- **解释层**——世界的说法（民间传说、谬论、梦学），以"世界以为"的口吻，挂锚于具体落地物
- **局外层**——创作痕迹（状态 / 待补 / 好点子），只做标注，不进正文

- 「帮我推导这个世界观」
- 「从这段剧情走向建立世界设定」
- 「检查我的世界设定有没有空位」
- 「补世界空位 / 做设定推导」
