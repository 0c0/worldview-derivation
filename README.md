# 世界推导框架（worldview-derivation）

一个从剧情走向推导完整世界观的框架 Skill（Trae / AI 助手可加载）。给一句剧情走向，它帮你把人、物、势力、法则等八类存在推清楚，且**只推到叙事够用的深度**，不把一个小片段挖成祖宗十八代。

> 安装：把 `SKILL.md` 放进你的 skill 目录即可通过 `/worldview-derivation` 或口头触发调用。

---

## 定位

正推流程：**先有走向，再立范围，后推世界，薄弱回补。**

- 产出＝**八类志书 ＋ 待补清单 ＋ 悬置疑点 ＋ 好点子库**
- 子分类承载剧情与服务世界不矛盾——主线之外的一切合理存在 ＝ 支线承载
- 存在皆由依据推导（公理 / 四决 / 法则 / 连带），推不出来的位置自动淘汰
- **深度决定广度**：叙事深度先于推导。"不入档"是合法答案，不是欠账

---

## 框架：四步闭环

| 步 | 环节 | 作用 |
| --- | --- | --- |
| 1 | **走向入锚** | 提炼顶层四决（起源 / 主角身份 / 势力分布 / 终局），并**深度定档**决定供给深浅 |
| 2 | **骨架落地** | 按八类志书立世界骨架，只立"类有存在"，不落细节 |
| 3 | **技法挂网** | 按叙事类型加载推导谱系（技法×八类子分类预设），充当推导检查网 |
| 4 | **多步推导-回补** | 逐片推导 + 逐片五审；空位补世界，推翻了走向则回修正，循环至无空位 |

产出前必经**拷问审稿**（五审），闯不过不算推导完成。

## 核心机制

### 推导轮 · 七步循环
整套推导**多轮回合、逐轮收敛**，不是一次走完。每轮七步：

1. 输入剧情走向 → 2. 拆分切片 → 3. 分析剧情重点（区分主线/支线）→ 4. 拷问（一次）→ 5. 逐片补全八类（逐片五审）→ 6. 输出推导后的走向（附情节节点等垂钩）→ 7. 决策闸（是否进入下一轮）。

闸门是**人为闸**——第 7 步始终交还用户决定，不由推导自己一路闯到底。

### 八类档案轴
统一脊柱 `本质→生成→关系→终局`，每格必须显式给态（✔填平 / 待补 / 悬置），不得静默跳格。八类：

角色 / 事件 / 道具 / 势力 / 场景 / 世相 / 能力 / 法则。

### 深度定档 · 三档
小情节补小世界。按主跨度定供给，防止把机锋级挖成史诗级：

| 档 | 主跨度 | 推导供给 |
| --- | --- | --- |
| 片段 · 机锋级 | 一次事件/一场景/一机锋 | 只落直接支撑事件因果的存在，前史世代不入档 |
| 篇级 | 一篇/一集完整故事 | 直接因果＋必要背景连带，追一层来历 |
| 宏图 · 史诗级 | 一生/几代/跨地缘 | 全八类充足供给，追世代与边界 |

**关键约束——纵向 / 横向分治**：深度闸只砍纵向（前史、来历、世代），**不断横向在场供给**。且**档低≠不开存在**：凡这世界"确实有"的内容都必须推导入档，"不入档"只能用于世界确实没有那一类。

### 影音在场（镜头翻译器）
把"古色古香 / 连滚带爬 / 安静得可怕"这类状态词拆成**可进画面、可入声轨**的具象元素（视觉子层 + 听觉子层）。**声音的缺席同样是声音设计**："连虫鸣都没有"不是没声音，是"声音的空缺"本身落进档作情绪压强。影音在场是**静态罗列**（不编剧情），叙事推进另归情节节点；且须关照全部在场状态，不只挑高光。

### 拷问爬梯 · 五层
对每个"为什么"逐层下探、**不跳层**：L1 行为 → L2 条件 → L3 动机 → L4 结构 → L5 存在。上一层的答案接住下一层的提问；默认停层由深度档决定。

### 设定分级
- **强制填平（强需求）**＝必须落到具体形态，作者不填＝漏洞，推导强制回填。
- **可悬置**＝语义/来历/因果的"为什么"，依档位悬置，但**不吞在场可见之相**。
- **可升降档（弱需求）**＝能靠泛指撑住、本轮不落实形也行；随剧情需要可升降档。
- 判级测试：作者若故意不写，读者会不会觉得故事有洞？→ 会则强制填平。

### 拷问审稿 · 五审（产出即设防）
强制回环，闯不过不能叫推导完成，且**一关一关闯**、逐关闭合：

1. **一关 · 锚点一致**——靠的和你写的是不是同一套？
2. **二关 · 亮相时机**——救场关键是否该早现却拖到收尾？
3. **三关 · 因果真闭合**——"靠这个能成"是真成了还是靠运气？
4. **四关 · 情绪有回声**——惹起的情绪有没有落到实处的回响？
5. **五关 · 色调没跑偏**——定下的基调与写的浓淡一致吗？

判定三档：✔过｜✎须修（给改法）｜⊘修不了→降格（丢悬置/好点子库）。

### 逐片推导纪律
**一次＝一片；一轮＝把全部切片逐片各过一遍。** 每执行一次只推一整个切片，八类在场铺开、五审、闭合后，再推下一片。禁止一次把整篇切片×八类铺满——那正是"看起来在推导、实际在瞎抄设定"的伪装。

## 核心信念

- 存在皆由依据推导，推导不出来的位置自动淘汰
- 作者裁决项不猜，停下问作者；纯世界因果缺失才从给定设定里显影
- 只验世界内部自洽，不用"现实常识/正常人会怎样"去判断世界
- 创作先于记载；落地先于解释；解释必挂锚（"世界的说法"入解释层，不污染真相层）
- 裁决即生效，不设复审

## 三层记录

- **真相层**：世界本来的样子，志正文本色，客观叙述
- **解释层**：世界的说法，以"世界以为"口吻，挂锚于落地物
- **局外层**：创作痕迹（状态/待补/更新/好点子库），只露标注与元数据，不进正文
