# 世界推导框架（worldview-derivation）

> **你给一段剧情，它告诉你：这个世界里应该有什么。**

---

## 这是什么

**一个由剧情反推世界的创作 Skill。**

你写了一段剧情走向——哪怕只有一句话——它会一类一类地往下推，告诉你这个世界里该有哪些人、哪些事、哪些东西、哪些规矩，以及每一样**为什么该存在**。

推不出依据的，它不硬凑；已经够用的，它不往下硬挖。

它干的**唯一一件事**，就是回答一个问题：

> **这个世界里，应该有什么？**

## 你会拿到什么

| 产出 | 内容 |
| --- | --- |
| **八类推导结果** | 角色 / 事件 / 道具 / 势力 / 场景 / 世相 / 能力 / 法则。这个世界该有的东西，每样都沿各自那一类的档案轴逐格表了态 |
| **待补清单** | 还缺什么，每一条都说清「为什么缺」 |
| **悬置的问题** | 剧情需要它存在、却推不出由来的，挂在这儿，不用再纠结 |
| **好点子库** | 想到但这个故事用不上的好想法，存着，哪天要用了能捞回来 |

每推完一轮，另附一条**待补方向**——「下一步还能往哪补」：还差什么、哪条该挂起来、有什么点子、哪条该再往深推，各指一条。它跟着每轮走，不是最后的交付。

写出来分三层，互不污染：

- **真相层**——世界本来的样子，客观写
- **解释层**——世界里的说法（传说、迷信、误传），用「他们以为」的口吻，挂在具体的东西上
- **局外注**——你自己的笔记（哪儿还缺、哪儿悬着、有什么点子），只做标记，不进正文

## 它不做什么

| 不做 | 说明 |
| --- | --- |
| **不编故事** | 剧情走向是你给的。它只负责把走向背后的世界补实，不替你推进剧情 |
| **不替你写设定** | 作者没给的内容，它标「待补」或回来问你，**不会自己编一个填上**。它推的是「这里该有什么」，不是「这里具体是什么样」 |
| **不给通用设定包** | 不会塞给你「常见的魔法体系分五种」这类模板。每一条都从你的剧情里推 |
| **不追求「全」** | 宁可低估也不充水。「这里不用管」是它会给出的正经答案 |
| **不替你决定** | 每一轮推完都停下来。扩不扩、往哪扩，你说了算 |

## 快速开始

**装**：把 `SKILL.md` 放进支持 Skill 的 AI 助手的 skill 目录。

**用**：直接说话就行——

```
帮我推导这个世界观
从这段剧情走向建立世界设定
看看我的设定还缺什么
补一下世界空位
```

## 一个具体例子

下面是真跑一遍的对话。走向是：**小红帽进林子 → 遇上狼 → 跳河跑了**。

**你**

> 帮我推导这个世界观。走向是：小红帽进林子 → 遇上狼 → 跳河跑了。

**它**

> 开工前先确认四件大事——这几个我不替你猜：**起源**（有没有超自然）、**主角是谁**、**势力有哪几方**、**最后落到哪**。
>
> 另外这段只扛一条事件链，建议按**片段级**推——只补直接撑着它的东西，前史世代一律不查。

**你**

> 一个普通村子，没有超自然。主角就是村里的孩子。势力就村子跟林子两边。结局她脱身了，狼没追上。

**它**

> 第 1 轮。先切四片：**入林 → 林中行进 → 遇狼 → 跳河**。中间那片是身体必须走完的过渡，跳不得。
>
> 说清一件事：**我只推「这里该有什么」，不替你把它们写成什么样。** 你没给的，我要么标待补、要么回头问你。
>
> 每一片都要把八类各过一遍。第一片长这样：
>
> | 片 | 角色 | 事件 | 道具 | 势力 | 场景 | 世相 | 能力 | 法则 |
> | --- | --- | --- | --- | --- | --- | --- | --- | --- |
> | S1 入林 | 主角：该有 **◻** | 跨林缘 **◻** | 无 | 村子：背景在场 **◻** | 林子：与村贴邻 **✔** | 村对林的说法 **◻ 漏洞** | 认路 **◻** | 作者已裁无超自然 **✔** |
>
> **✔ 填平 ｜ ◻ 待补 ｜ ⏸ 悬置 ｜ 无（这一片里没有这类东西在场）**
>
> 三处要说清：
>
> - **道具为什么记「无」**——她空手进林，这一片里没有道具在起作用，这类在这一片刻即闭环。（「无」说的是"这一片没它"，不是"这世界没有道具"）
> - **世相为什么标漏洞**——「她凭什么敢进林子」的答案就落在这格上。这格必须有，你没给，所以标漏洞回填。
> - **势力与法则为什么得入档**——你裁了「村子跟林子两边」，也裁了「没有超自然」；裁过就是存在，不因为它这场戏没露面、也不因为它是一条「没有」就跳过。
>
> 一片推完先过五关，一关一关闯（**✔ 过 ｜ ✎ 须修 ｜ ⊘ 修不了，放弃它 ｜ – 你还没给输入，不判**）：
>
> - 锚点一致 **✔**
> - 依据早于使用 **✎ 须修**——那条河不能到跳河那一片才在世界里落档，得提前立住
> - 因果真闭合 **✎ 须修**——现在「入林 → 掉进河里脱身」是断的，像凭空冒出一条河救了她
> - 压强有承载 / 色调没跑偏 **–**——你还没给基调，这两关不判，也不替你定
>
> 四片都过完，给你两样：**主线支线**、**情节节点串**；另附一条**待补方向**——下一轮还能往哪补，各指一条。
>
> 停在这儿。两个问题得先答：**她凭什么敢一个人进林子？凭什么能脱身？** 不答，下一轮推不动。
>
> 下一轮推哪块——补村子、补世相、细化遇狼，还是把「狼」这条单独往深里推？

**你**

> 先补村子。

**它**

> 第 2 轮，以上一轮的输出当新输入。补村子要你给三样：**主角是谁**（年龄 / 身份 / 家）、**她跟村里的关系**、**村里对林子的说法**。给多少补多少，剩下的继续挂待补。

---

就这样一轮一轮走，每轮都把决定权交回给你。**它不会一路推到底、把整张世界地图填满。**

注意它上面做的事：**它推的是「该有什么」，不是「是什么」。** 凡是你不给的，它一个字都不编——这才是「推导」和「替你想」的分界。

## 「有什么」，分八类

一个世界里能存在的东西，无非这八种。它一类一类地问：

| 它在问 | 这一类叫 |
| --- | --- |
| 谁在动？ | **角色** |
| 发生过什么？ | **事件** |
| 用什么？ | **道具** |
| 谁聚成团？ | **势力** |
| 在哪儿？ | **场景** |
| 什么风气、什么说法？ | **世相** |
| 什么本事、什么学问？ | **能力** |
| 什么规矩、什么法则？ | **法则** |

每一样都不是填个名字就算数，得沿它那一类的**档案轴逐格推**。普遍落在这四问上：

```
它是什么  →  它怎么来的  →  它和谁有关  →  它最后怎样
```

**每格都要明确表态**——每一格都必须落一个标记：

| 标记 | 含义 |
| --- | --- |
| ✔ **填平** | 说清楚了，可以往下用 |
| ◻ **待补** | 这条迟早要给说法，先记着 |
| ⏸ **悬置** | 决定不追究了，就让它悬着 |
| ⊘ **不入档** | 这一类（或这一位）确实不必推——它说的是"没有这一类"，不是"这一片用不上" |

逐片表格里，某一类在这一片没有东西在场，记 **「无」**——那不是"没有这一类"，只是这一片用不上它。

过八类不是空手过。每种故事类型该往哪几类里找什么，框架预铺了一张取材清单（`references/genre-presets.md`，25 个类型各一套）。**每一片都照它逐档核一遍、逐档留痕**：这一档被这一片命中了、这一片用不上、还是挂不上出处被淘汰——三种下场各自写清。「没核过」和「核过、判了淘汰」分得出来，才谈得上把预设用实。

## 它凭什么说「应该有」

**每个存在都得有出处。** 出处只有四种：

- 世界的基本设定
- 你敲定的四件大事
- 世界的法则
- 从别的存在连带推出来的

挂不上出处的，**自动淘汰**。

于是有了一个听起来反常识、其实很好用的结论：

> **「这里不该有东西」，也是一个推导结果。**

大部分设定文档的毛病是只增不减——想到就写，写完堆着。这个框架会明确告诉你：这类东西你这个故事用不上，可以先记进「好点子库」。

**但「推不深」和「本就不存在」是两回事。** 眼前这场戏真正要用的东西——他凭什么敢进林子、穿什么、带什么、听得见什么——再小也得补齐。它管的是「祖上三代」这种纵向追问；**当场要用的横向供给，再小也补**。

## 推到多细，先商量好

同一个世界，写一场戏和写一个世代，需要的深度完全不是一回事。所以先定档：

| 你写的是 | 它只推 |
| --- | --- |
| 一场戏 / 一个片段 | 直接撑着这场戏的东西。前史、世代，一律不查 |
| 一篇完整的短故事 | 直接因果 + 必要的来历，往上追一层 |
| 一生 / 几代 / 跨地缘 | 八类全上，追世代、追边界 |

**拿不准就往低定**，真需要了再显式扩容——扩哪块就扩哪块，其余原样不动。

## 推出来的东西必须能看能听

你写的「古色古香」「连滚带爬」「安静得可怕」——这是**感觉**，还不是「有」。

一个存在既然在，就得说清它在画面里长什么样、在声轨里是什么声。所以它会做一次翻译：

> **连滚带爬** → 手撑青石 / 膝盖顶门槛 / 鞋在石板上打滑 / 喘 / 脚步乱

**「没有声音」也算声音。**「连虫鸣都没有」不是没声音——是这份「空」本身要落进去，当情绪压力用。

这一层只做罗列，不编剧情。剧情怎么走是另一回事，不混着来。

## 跨片的东西，单独记账

剧情切成片之后，有些东西是**贯穿的**——那个信物、那个人、那条流传的说法。它们不该每片各写各的。

所以它会单立一本账，每一片都过一遍：**谁在账上、这一片在场没有、状态跟上一片接不接得上**。接不上，分三种处置：

| 判定 | 意思 |
| --- | --- |
| **续** | 照上一片的状态往下走 |
| **变** | 状态变了——写清从什么变成什么 |
| **调** | 这个元素本身要改：往深里推一层、降下来、换掉、或新立一条 |

「调」必须明写出来，写清改了哪一条、改成什么。账本身也会变：某个东西可能在某一片起才上账，或从此不再承载。

**跨片飘移就是这么被堵住的**——每片单看都合法、连起来却对不上，是这类推演最容易出的错。

## 交付前先自己过五关

每一片推导闭合之前，都得自己闯过这五道：

1. **锚点一致**——你写的，跟推导时依据的是不是同一套？
2. **依据早于使用**——你靠它成事的那件东西，世界里是不是早就该有落档，而不是收尾才凭空立起来？
3. **因果真闭合**——「靠这个能成」，是真成了，还是其实靠运气？
4. **压强有承载**——你压上的情绪，世界里有没有对应的东西撑着它？
5. **色调没跑偏**——说好的基调，写着写着跑偏了吗？

过不了就改；改不了就降级，丢进「悬置」。**不许含糊过去。**

后两关靠基调：你还没给基调时，它们判「不判」，框架不替你定。

## 文件结构

```
.
├── SKILL.md                    完整方法论 —— 一轮七步怎么走、八类各自怎么推、
│                               提问怎么逐层下探、五关的判定标准
├── references/
│   ├── genre-presets.md        按故事类型预铺的取材清单 —— 25 个叙事类型，
│   │                           每个类型该往八类里找哪些预设，带检索索引
│   └── craft-notes.md          技法判例附页 —— 视听怎么拆、调性两关怎么判、
│                               过渡怎么算漏节、爬梯与五关的判例
└── README.md                   你正在看的这份
```

上面讲的是**它是什么、给你什么**。具体每一步怎么执行，都在 [`SKILL.md`](./SKILL.md)；查表用的两份材料单独放在 [`references/`](./references)——取材清单按类型现查，技法判例按情形现查，都不用通读。
