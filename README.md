# 世界推导框架（worldview-derivation）

**你手里有一段剧情，它能帮你把这段剧情背后的世界推清楚——不多推，也不少推。**

---

## 你是不是也这样

- 写主角半夜闯进一座废弃小镇，写完发现说不通：他为什么不怕？镇上的人去哪了？他手里那盏灯哪来的？
- 于是开始补设定。补着补着写了一整页建镇史、三百年前的战争、三任镇长的家谱——然后想起来，主角在这镇子只待二十分钟。
- 或者反过来：只写了一句"这是一座被诅咒的镇子"，真到写戏时什么都撑不住。

**这个框架就是治这两件事的。** 它的判断标准只有一条：

> **这段剧情需要多深的世界，就只推多深。**

多的不写，不够再补。所以在这里，"这里不用管"是一个**正经答案**，不是偷懒。

---

## 用起来大概是这样的

你给它一段走向：

> 小红帽进林子 → 遇上狼 → 跳河跑了

它不会一口气把整个宇宙吐给你。它一轮一轮地推，**每轮结束时停下来问你一句**：

```
第 1 轮
  ├─ 先跟你敲定四件大事：世界怎么来的、主角是谁、有几方势力、最后落到哪
  ├─ 把走向切成片：进林 / 遇狼 / 跳河
  ├─ 一片一片过，每片都问一遍：
  │   这片里有谁？发生了什么？用了什么？谁跟谁一伙？
  │   在哪儿？什么风气？会什么本事？世界有什么规矩？
  ├─ 每片写完，自己先过五道自检
  └─ 把推完的结果回写成一段更完整的走向，然后问你：
     还要往下推吗？推哪块？

第 2 轮
  └─ 拿上一轮的结果当新输入，接着来……
```

**关键在最后那个问号。** 它不会一路推到底把整张世界地图填满——每一轮结束，方向盘都回到你手里。

---

## 你会拿到四样东西

**八张清单**——谁 / 发生过什么 / 用了什么 / 谁聚团 / 在哪儿 / 什么风气 / 什么本事 / 什么规矩。

每条都按四格写：**它是什么 → 它怎么来的 → 它和谁有关 → 它最后怎样。** 每格必须明确表态，不许跳过：

- ✔ **填好了**——说清楚了
- ◻ **待补**——这条迟早要给说法，先记着
- ⏸ **悬置**——决定不追究了，就让它悬着

另外三样：

| | |
|---|---|
| **待补清单** | 现在还缺什么，每一条都能说清"为什么缺" |
| **悬置的问题** | 剧情需要它存在、但确实推不出由来的，挂这儿，以后不用再纠结 |
| **好点子库** | 想到但这个故事用不上的好想法，放这儿，哪天要用了能捞回来 |

---

## 它给自己定的三条规矩

**第一，每个设定都得有出处。**
清单里的每一条，都要能挂到"你已经给过的事实"上。挂不上去的，删掉；实在想留，就先回来问你——**它不替你瞎猜**。

**第二，先商量推多深，再动手。**
你故事只有一场戏，它就不会去查这场戏里那些人的祖上三代。但它**不会**因此漏掉眼前要用的东西——"他凭什么敢进林子、穿什么、带什么、听得见什么"，这种当场就要用的，再小也给你补齐。

**"推不深"和"这一类不存在"是两回事**，它分得清。

**第三，交给你之前先自己过五关。**

1. 你写的，跟你推导时依据的是不是同一套？
2. 那个救场的关键道具，是不是该早出现却拖到了结尾？
3. "靠这个能成"——是真成了，还是其实靠运气？
4. 你在这儿惹起的情绪，后面有没有回响？
5. 说好的基调，写着写着跑偏了吗？

过不了就改；改不了就降级，丢进"悬置的问题"。**不许含糊过去。**

---

## 一个挺好用的能力：把感觉变成能拍的东西

你写的"古色古香""连滚带爬""安静得可怕"——这些是**感觉**，不是画面。

它会帮你拆成能拍、能录的东西：

> **连滚带爬** → 手撑青石 / 膝盖顶门槛 / 鞋在石板上打滑 / 喘 / 脚步乱

而且**"没有声音"也算声音**。"连虫鸣都没有"不是没声音——是这份"空"本身要写进去，当情绪压力用。

这一层只做罗列，不编剧情。剧情怎么走是另一回事，不混着来。

---

## 写出来的东西分三层，互不污染

- **真相层**——世界本来的样子，客观写
- **解释层**——世界里的说法（传说、迷信、误传），用"他们以为"的口吻写，挂在具体的东西上
- **局外注**——你自己的笔记（哪儿还缺、哪儿悬着、有什么点子），只做标记，不进正文

## 装

把 `SKILL.md` 放进支持 Skill 的 AI 助手的 skill 目录就行。之后直接说话就能用：

- 「帮我推导这个世界观」
- 「从这段剧情走向建立世界设定」
- 「看看我的设定还缺什么」
- 「补一下世界空位」

---

## 就两个文件

```
├── SKILL.md    完整方法论 —— 每轮七步各做什么、八类各自的写法、
│               提问怎么逐层往下、五道自检的标准、按故事类型预铺的取材清单
└── README.md   你正在看的这份
```

这上面讲的是**怎么用**。至于**为什么这么设计**——为什么只砍纵向不砍横向、深度分成几档、提问怎么一层层下去——都在 [`SKILL.md`](./SKILL.md) 里。
